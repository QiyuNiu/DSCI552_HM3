# DSCI 552 Homework 3

This repository contains Qiyu Niu's Homework 3 submission.

## Contents

- `notebook/Niu_Qiyu_HW3.ipynb`: completed and executed notebook
- `data/AReM/`: the AReM activity-recognition data used by the notebook
- `requirements.txt`: Python dependencies

The notebook covers the required Homework 3 material only:

1. AReM train/test split and time-domain feature extraction
2. Standard-deviation estimates with 90% bootstrap confidence intervals
3. ISLR 3.7.4 conceptual answers

## Run

Create an environment and install the dependencies:

```bash
python -m pip install -r requirements.txt
```

Start Jupyter from the repository root and open the notebook:

```bash
jupyter notebook notebook/Niu_Qiyu_HW3.ipynb
```
